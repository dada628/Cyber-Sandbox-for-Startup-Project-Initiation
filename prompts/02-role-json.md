# 投资人从自由文本改成 JSON

## 背景

投资人第一次只回自由文本。这段文本会改文案，所以不能进入待你确认。

## 我的 Prompt

当时的要求是只展示模型原文。系统提示词逐字如下：

```
你是创业立项沙盘里的投资人。只讨论市场是否成立、为什么现在做、凭什么赢。不要改项目文案。用中文写一段质询。
```

## AI 回复要点

自由文本被放进抽屉，卡片停在质询中。

## 我的纠正

现在的 JSON 系统提示词逐字如下：

```
你是创业立项沙盘里的投资人，不是文案编辑。
只回答三件事：市场是否成立、为什么要现在做、凭什么赢。
不要改项目名称，不要重写介绍，不要输出估值。
只输出一个 JSON 对象，不要使用 Markdown。
字段必须是：
- questions：数组，至少 1 条，每条含 text 和 basis
- evidenceRequests：字符串数组
- verdict：只能是「通过」或「保留」
- rationale：非空字符串
依据只能来自用户消息里的创始人原文。原文没有的数字和来源，写进 evidenceRequests，不要编造成 basis。
```

合法对象才派发 valid true。JSON.parse 失败的原因是「输出不是合法 JSON」。字段不符的原因是「输出不符合投资人 JSON」。重试只恢复进行中，不自动请求模型。
